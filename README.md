# 🌸 日本語 勉強しましょう (Nihongo Voice Quiz Web)

เว็บแอปพลิเคชันสำหรับฝึกฝนภาษาญี่ปุ่น ท่องจำคำศัพท์ คันจิ ฮิรางานะ คาตาคานะ และไวยากรณ์ตามหลักสูตร **มินนะ โนะ นิฮงโกะ (Minna no Nihongo) เล่ม 1 - 4 (บทที่ 1 ถึง 50)** พร้อมระบบตอบคำถามด้วยเสียง (Voice Recognition) และเสียงอ่านภาษาญี่ปุ่น

---

## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

- 📚 **ครอบคลุมเนื้อหา Minna no Nihongo เล่ม 1 - 4**:
  - เล่ม 1: บทที่ 1 - 12
  - เล่ม 2: บทที่ 13 - 25
  - เล่ม 3: บทที่ 26 - 38
  - เล่ม 4: บทที่ 39 - 50
- 🎙️ **ระบบ Voice Quiz (ฝึกออกเสียง)**: ตอบคำถามด้วยการพูดภาษาญี่ปุ่นผ่านไมโครโฟน พร้อมการตรวจสอบความถูกต้องด้วย Web Speech API
- 🔊 **ระบบอ่านออกเสียงคำศัพท์ (TTS)**: ฟังสำเนียงการออกเสียงภาษาญี่ปุ่นที่ถูกต้อง
- 📝 **ระบบแจ้งเพิ่ม/แนะนำคำศัพท์**: ผู้เรียนสามารถส่งคำศัพท์ คันจิ หรือคำอ่านที่ต้องการเพิ่มเติมเข้าสู่ระบบได้
- 🎨 **ดีไซน์สวยงามสไตล์อนิเมะ**: ตกแต่งด้วยกลิ่นอายญี่ปุ่น เอฟเฟกต์กลีบซากุระร่วง และมาสคอต Chibi Yuki รองรับ Responsive ทั้งบนคอมพิวเตอร์และมือถือ

## 💻 สิ่งที่ต้องเตรียมก่อนติดตั้ง (Prerequisites)

ก่อนเริ่มติดตั้ง ตรวจสอบให้แน่ใจว่าเครื่องของคุณมีโปรแกรมต่อไปนี้:

1. **[Node.js](https://nodejs.org/)** (แนะนำเวอร์ชัน 18.x ขึ้นไป)
   - ตรวจสอบเวอร์ชันใน Terminal:
     ```bash
     node -v
     npm -v
     ```
2. **Web Browser ที่รองรับ Web Speech API**:
   - แนะนำ: **Google Chrome** หรือ **Microsoft Edge** (เพื่อการใช้งานระบบเสียงและไมโครโฟนที่สมบูรณ์ที่สุด)
3. **[Git](https://git-scm.com/)** (สำหรับ Clone โปรเจกต์)

---

## 🚀 ขั้นตอนการติดตั้งและรันโปรเจกต์ (Installation & Setup)

### 1. ดาวน์โหลดโค้ดโปรเจกต์ (Clone Repository)

เปิด **Terminal** หรือ **PowerShell** แล้วรันคำสั่ง:

```bash
git clone https://github.com/NarisPK/JapanClass.git
```
หรือหากมีโฟลเดอร์โปรเจกต์อยู่แล้ว ให้เข้าไปยังโฟลเดอร์โปรเจกต์:
```bash
cd voice-quiz-web
```
*(หรือ `cd JapanClass` ตามชื่อโฟลเดอร์ของคุณ)*

---

### 2. ติดตั้ง Dependencies

รันคำสั่งเพื่อติดตั้งแพ็กเกจที่จำเป็น (Express):

```bash
npm install
```

---

### 3. เริ่มต้นเปิดเซิร์ฟเวอร์ (Start Server)

รันคำสั่งเริ่มการทำงานของเซิร์ฟเวอร์:

```bash
node server.js
```

เมื่อเซิร์ฟเวอร์เริ่มทำงานสำเร็จ จะมีข้อความแสดงในหน้าจอ:
```text
Server is running at http://localhost:3000
```

---

### 4. เปิดเข้าใช้งานเว็บไซต์

เปิดโปรแกรมเบราว์เซอร์ (Chrome หรือ Edge) แล้วเข้าไปที่:
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🎙️ การเปิดสิทธิ์การใช้งานไมโครโฟน (Microphone Permissions)

สำหรับการใช้งานโหมดตอบคำถามด้วยเสียง (Voice Quiz):
1. เมื่อเข้าหน้าเว็บครั้งแรก เบราว์เซอร์จะแสดงหน้าต่างขออนุญาตใช้งานไมโครโฟน
2. ให้กด **"อนุญาต" (Allow)**
3. หากเผลอกดปิดหรือปฏิเสธ:
   - กดที่ไอคอนแม่กุญแจ 🔒 ทางซ้ายของช่องใส่ URL บนเบราว์เซอร์
   - ปรับการตั้งค่าไมโครโฟน (Microphone) ให้เป็น **"อนุญาต" (Allow)**
   - รีเฟรชหน้าเว็บ (F5)

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
voice-quiz-web/

├── public/                      # ไฟล์หน้าบ้าน (Frontend) ทั้งหมด
│   ├── index.html               # หน้าเว็บหลักของแอปพลิเคชัน
│   ├── css/
│   │   └── style.css            # สไตล์ตกแต่งเพิ่มเติมและอนิเมชัน
│   ├── images/                  # รูปภาพพื้นหลังและมาสคอต Chibi
│   └── js/
│       ├── app.js               # Logic หลักของเกม, เสียงพูด และการควบคุมหน้าเว็บ
│       ├── quizData.js          # คลังคำถามและตัวเลือก
│       └── data/                # ข้อมูลคำศัพท์และไวยากรณ์แยกบท (เล่ม 1 - 4)

├── server.js                    # Express Backend สำหรับเสิร์ฟไฟล์และ API
├── package.json                 # ข้อมูลโปรเจกต์และ Dependencies
└── .gitignore                   # รายการไฟล์ที่ไม่ต้องการนำขึ้น Git
```

## 🛠️ การแก้ไขปัญหาที่พบบ่อย (Troubleshooting)

- **พอร์ต 3000 ชนกับโปรแกรมอื่น (`EADDRINUSE: address already in use :::3000`)**:
  - ตรวจสอบว่ามี Terminal อื่นรัน `node server.js` ค้างอยู่หรือไม่ ให้ปิด Terminal นั้นก่อน หรือกด `Ctrl + C` เพื่อหยุดการทำงานแล้วรันใหม่
- **ระบบเสียงพูดไม่ทำงาน**:
  - ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต (Web Speech API ในบางบราวเซอร์ต้องใช้อินเทอร์เน็ตในการแปลงเสียง)
  - แนะนำให้ใช้ Google Chrome หรือ Microsoft Edge เพื่อประสิทธิภาพสูงสุด
